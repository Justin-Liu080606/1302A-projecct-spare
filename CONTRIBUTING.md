# Contributing (team CS1302 group06)

The course requires a **real public Git repository** and regular, attributable collaboration. Everyone should contribute genuinely; do not fabricate Git history or authorship. Coordinate tasks, test changes and explain each person's contribution in the presentation.

Suggested division of work (adapt to actual team skills):

1. **Scheduling**: refine `study_plan/planner.py` and add cases in `tests/test_planner.py`.
2. **Reusable exports and notebooks**: maintain `study_plan/exports.py`, `examples/`, and API tests.
3. **Web UI, packaging and documentation**: maintain `study_plan/static/`, `pyproject.toml`, `README.md` and publishing checks.

Workflow: create an issue, branch from main, make a small reviewed PR, run `python -m unittest discover -s tests -v`, merge, and repeat. At the end verify visible contributions from all team members.

Please agree on a software license as a group before public publication. This project intentionally does not choose a license on behalf of all contributors.
